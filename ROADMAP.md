# Roadmap

## Phase 1 — Foundation

- Establish the research narrative framework.
- Create starter chapters and policy themes.
- Build the first version of the website shell.
- Publish contributor guidance and issue templates.

## Phase 2 — Data and signal build

- Add jurisdictional policy dataset scaffolding.
- Implement data ingestion and classification pipelines.
- Create content sections for regulatory risk, founder location, and survival signals.
- Define contribution-friendly tasks for analytics and visualization.

## Phase 3 — Community growth

- Curate a backlog of issues with clear scope and acceptance criteria.
- Add `good first issue`, `help wanted`, and `research` labels.
- Publish contributor journey documentation.
- Invite reviewers and maintainers to help triage contributions.

## Phase 4 — Reporting and publishing

- Build exportable narrative summaries and data briefs.
- Add interactive charts and policy heat maps.
- Optimize the website for readability, accessibility, and sharing.
