# The Regulation Reckoning

## Mission

The Regulation Reckoning is a Stellar ecosystem Web3 platform focused on regulatory resilience, on-chain signal analysis, and storytelling for builders and ecosystem stewards.

This repository is designed to support a Stellar-native open-source project:
- Horizon network integration and on-chain metrics
- modular research content and data artifacts
- clear contribution pathways for Web3 engineering, policy, and analytics
- a developer-friendly site for showcasing Stellar network insights

## What contributors can do

1. Add Stellar network signal analysis and transaction-level research.
2. Build Web3 UI components that connect to Horizon data.
3. Improve on-chain data ingestion and policy mapping.
4. Create issue templates and workflows for sustainable contributor growth.

## Project structure

- `src/` — React application, UI components, and Stellar Horizon helpers
- `content/` — research chapters, narrative briefs, and policy analysis notes
- `analysis/` — analytics pipelines, network metrics, and data tooling
- `docs/` — architecture and contributor documentation for a Web3 project
- `.github/` — issue templates, pull requests, and collaboration guidance

## Getting started

1. Install dependencies: `npm install`
2. Run the dev server: `npm run dev`
3. Read `CONTRIBUTING.md` and `docs/CONTRIBUTOR_GUIDE.md`
4. Pick a contribution pathway: research, data, engineering, or community.

## Vision

The Regulation Reckoning helps contributors map how global regulations influence Stellar projects, network resilience, and the broader Web3 ecosystem.
